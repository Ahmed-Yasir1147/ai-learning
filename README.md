# AI Learning

A collection of code, experiments, and mini-projects I built while learning **Artificial Intelligence and Machine Learning from April to September 2026**.

This repository primarily serves as a record of my hands-on learning. The code ranges from small implementations and experiments to larger mini-projects. Some notebooks and scripts are intentionally lightweight and may not contain extensive documentation, as they were created primarily to understand and practice different concepts.

## Machine Learning

Contains implementations and experiments covering the major areas of classical machine learning:

* **Supervised Learning** — Classification and Regression
* **Unsupervised Learning** — Clustering, Dimensionality Reduction, and Anomaly Detection
* **Reinforcement Learning** — Fundamental RL concepts and value-based algorithms

## Deep Learning & Generative AI

Contains the deep learning and modern AI concepts I studied, including:

* Artificial Neural Networks (ANNs)
* Convolutional Neural Networks (CNNs)
* Recurrent Neural Networks (RNNs)
* Transformers
* Retrieval-Augmented Generation (RAG)
* Generative Adversarial Networks (GANs)
* Diffusion Models
* AI APIs — Gemini

## Agentic AI

Experiments with agentic AI and AI agents, currently focused on:

* **Agno**
* Tool-using agents
* Planning and multi-step agent workflows

## Learning Approach

The repository reflects a progression from fundamental concepts toward more advanced AI systems:

**Machine Learning → Deep Learning → Transformers & Generative AI → RAG → Agentic AI**

Most of the work was built while learning the concepts rather than as production-ready software. Therefore, the emphasis is on **understanding concepts through implementation and experimentation** rather than polished architecture, documentation, or deployment.

## Timeline

**April 2026 → September 2026**

During this period, I worked through the fundamentals of machine learning and progressively moved toward deep learning, transformers, RAG, and agentic AI.

This repository is a snapshot of that learning process and will continue to evolve as I build more substantial AI projects.
